# A2A（Agent-to-Agent）— AI 彼此協作的對講機

> **白話說：** MCP 解決「AI 怎麼連工具」，A2A 解決「一個 Agent 怎麼找另一個 Agent 合作」。

---

## 它到底是什麼？

當工作不再由單一 AI 完成，Agent 需要能夠：

- 宣告自己能做什麼
- 接收另一個 Agent 的任務
- 回報進度與結果
- 處理需要人工確認的步驟
- 支援長時間任務、取消與失敗

A2A 是描述 Agent 對 Agent 協作的協議與架構方向。實際支援、版本與互通性仍應以官方規格和各工具文件為準。

## 生活比喻 / 實際例子

- **MCP**：Agent ↔ 工具或資料來源，例如查文件、操作瀏覽器
- **A2A**：Agent ↔ Agent，例如研究 Agent 把結果交給寫作 Agent

這就像公司裡的對講機：不是讓所有員工共享同一張辦公桌，而是讓不同部門能用清楚的格式交接任務。

## 為什麼要知道這個詞？

不要把多個模型輪流發言就叫做 A2A。可維護的 Agent 協作仍需要身份驗證、能力描述、權限邊界、結果格式、逾時、重試與可觀測性。

目前 A2A 生態仍在快速演進，閱讀產品文件時要標示版本，不要把草案或單一產品能力寫成所有 Agent 都支援的穩定標準。
