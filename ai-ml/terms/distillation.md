# Distillation（蒸餾） — 把大 AI 的能力「濃縮」到小 AI 裡

> **白話說：** 就像把一整本百科全書的精華濃縮成一本口袋書——內容少了，但最重要的知識都還在。Distillation 就是讓小模型學會大模型的本事。

---

## 它到底是什麼？

**Distillation（知識蒸餾）** 是一種把大型 AI 模型的能力轉移到小型模型的技術。

原理很簡單：
1. 先有一個很強的大模型（Teacher，老師）
2. 讓大模型回答大量問題，產生「標準答案」
3. 用這些答案來訓練一個小模型（Student，學生）
4. 小模型學會了大模型的「思考方式」

```
大模型（GPT-5 等級）         小模型（手機能跑）
┌─────────────────┐         ┌──────────────┐
│ 超強但超貴超慢    │ ──蒸餾→ │ 沒那麼強      │
│ 需要超級電腦      │         │ 但便宜又快    │
│ 一次回答要 $0.03  │         │ 一次 $0.0001  │
└─────────────────┘         └──────────────┘
```

[DeepSeek](deepseek.md) 的成功就大量運用了 Distillation 技術。[SLM](slm.md) 很多也是從大模型蒸餾出來的。

## 生活比喻 / 實際例子

想像一個米其林主廚（大模型）教一個學徒（小模型）：
- 主廚不是教他所有知識，而是讓他看自己怎麼做菜
- 學徒模仿主廚的做法，學會了 80% 的功力
- 學徒開不了米其林餐廳，但開一間好吃的小店綽綽有餘

**造句**：
- 「我們把 GPT-5 的回答拿來做 **Distillation**，訓練出一個專用的小模型」
- 「**蒸餾** 出來的模型只有 7B 參數，但在我們的任務上表現跟大模型差不多」
- 「DeepSeek 用了 **Distillation** 技術，所以能用低成本達到高水準」

## 為什麼要知道這個詞？

- 理解為什麼小模型能越來越強——很多都是從大模型蒸餾出來的
- 企業想要便宜又好用的 AI，Distillation 是關鍵技術
- 跟 [SLM](slm.md)、[DeepSeek](deepseek.md)、[Fine-tuning](fine-tuning.md) 密切相關
