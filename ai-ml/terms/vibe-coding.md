# Vibe Coding — 用嘴巴寫程式，不看程式碼直接用

> **白話說：** 就像你跟裝潢師傅說「我要北歐風、要有中島」，然後完全不看施工圖就讓他動工——Vibe Coding 就是用自然語言告訴 AI 你要什麼功能，不仔細審查程式碼就直接用。

---

## 它到底是什麼？

Vibe Coding 是 2025 年由 Andrej Karpathy（前 Tesla AI 主管、OpenAI 共同創辦人）提出的詞，描述一種新的「寫程式」方式：

1. 你用自然語言描述你要什麼功能
2. AI（像 [Claude Code](../../software-engineering/terms/claude-code.md)、[Cursor](../../software-engineering/terms/cursor.md)）幫你生成程式碼
3. 你不仔細看程式碼，直接跑跑看
4. 能動就好，不能動就再跟 AI 說哪裡有問題

關鍵特徵是：**你不真的去讀或理解那些程式碼**。你只是「憑感覺（vibe）」在寫程式。

```
傳統寫程式：
  需求 → 設計 → 寫程式碼 → 測試 → 修改 → 上線

Vibe Coding：
  需求 → 跟 AI 講 → 能動嗎？→ 能動就好 👍
                              → 不能動就再講一次 🔄
```

## 生活比喻 / 實際例子

想像你在餐廳點餐：

- **傳統寫程式** = 你自己進廚房煮，每個步驟都清楚
- **Vibe Coding** = 你跟廚師說「我要一個有肉有菜的便當」，端出來能吃就好，你不管他怎麼煮的

**造句**：
- 「我昨天 **Vibe Coding** 了一個小工具，半小時就搞定，雖然程式碼我看不太懂」
- 「這個 side project 我就 **Vibe Coding** 一下，不用太講究」
- 「正式產品不能 **Vibe Coding** 啦，出事了沒人看得懂怎麼修」

## 為什麼要知道這個詞？

- 2025-2026 年最熱門的 AI 編程話題之一，到處都在討論
- 它降低了寫程式的門檻——不會寫程式的人也能做出東西
- 但也引發爭議：這樣產出的程式碼品質堪憂，可能有安全漏洞、效能問題
- 跟 [Slop](slop.md) 問題直接相關——AI 生成的低品質程式碼越來越多
- 了解這個詞，你就能參與「AI 會不會取代工程師」的討論
