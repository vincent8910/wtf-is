# SLM（小型語言模型） — 輕巧版的 AI，跑在你自己的電腦上

> **白話說：** 如果 [LLM](llm.md) 是一台大卡車——什麼都能載但又貴又耗油，SLM 就是一台機車——載不了那麼多東西，但便宜、靈活、停車方便，日常夠用。

---

## 它到底是什麼？

SLM 是 **Small Language Model（小型語言模型）** 的縮寫。

跟動輒幾千億參數的 [LLM](llm.md) 不同，SLM 通常只有幾十億到幾百億參數，但針對特定任務做了優化。

| | LLM（大型） | SLM（小型） |
|--|---|---|
| 參數量 | 數千億 | 數十億～數百億 |
| 運行環境 | 需要雲端伺服器 | 可以跑在筆電、手機上 |
| 成本 | 高（API 費用或昂貴硬體） | 低（自己的電腦就能跑） |
| 能力 | 什麼都能做 | 特定任務做得好 |
| 隱私 | 資料要傳到雲端 | 資料留在本地 |
| 速度 | 要等回應 | 通常更快 |

代表性的 SLM：
- **Phi-3**（Microsoft）：小到能跑在手機上
- **Gemma**（Google）：輕量級開源模型
- **Llama 3 8B**（Meta）：80 億參數的精簡版

## 生活比喻 / 實際例子

想像你要搬東西：

- **LLM** = 請搬家公司的大卡車。什麼都搬得動，但要預約、要付大筆錢
- **SLM** = 自己的機車。搬不了冰箱，但搬幾箱書綽綽有餘，隨時能出發

企業選擇 SLM 的原因通常是：
- **隱私**：機密資料不想傳到 OpenAI 的伺服器
- **成本**：每天幾萬次呼叫，用 API 太貴
- **速度**：需要即時回應，不能等雲端

**造句**：
- 「我們公司內部用 **SLM** 做文件摘要，資料不用出公司」
- 「手機上的 AI 助手用的是 **小型語言模型**，不需要連網就能用」
- 「這個任務不需要 GPT-5，用 **SLM** 就夠了，省錢」

## 為什麼要知道這個詞？

- 不是所有場景都需要最大最貴的 AI——SLM 是更務實的選擇
- 企業端部署 AI 時，SLM 因為隱私和成本優勢越來越受歡迎
- 了解 LLM 和 SLM 的差別，你就能參與「我們該用哪種 AI」的討論
- 跟 [Shadow AI](shadow-ai.md) 議題相關——公司可以用 SLM 提供官方 AI 工具，減少員工私用外部 AI
