# WebAssembly (WASM) — 讓瀏覽器跑得跟桌面程式一樣快

> **白話說：** 以前瀏覽器只能跑 [JavaScript](javascript.md)，速度有限。WASM 讓你可以把 C++、Rust 等高效能語言的程式碼放到瀏覽器裡跑——就像給瀏覽器裝了渦輪增壓引擎。

---

## 它到底是什麼？

**WebAssembly（簡稱 WASM）** 是一種可以在瀏覽器裡執行的低階程式碼格式，速度接近原生應用程式。

傳統網頁只能用 [JavaScript](javascript.md)，但 JS 對某些任務來說太慢了（如 3D 遊戲、影片編輯、AI 推論）。WASM 解決了這個問題：

```
傳統：C++ 程式 → 只能在電腦上跑
WASM：C++ 程式 → 編譯成 WASM → 在瀏覽器裡跑！
```

實際應用：
- **Figma**：設計工具，用 WASM 實現流暢的畫布操作
- **Google Earth**：3D 地球在瀏覽器裡流暢運行
- **Photoshop Web**：Adobe 把 Photoshop 搬到瀏覽器
- **遊戲**：Unity 遊戲可以直接在網頁上玩

## 生活比喻 / 實際例子

- **JavaScript** = 腳踏車，日常代步夠用
- **WASM** = 機車，需要速度的時候上場

兩者可以並存——簡單的互動用 JS，需要效能的部分用 WASM。

**造句**：
- 「Figma 之所以在瀏覽器裡這麼流暢，是因為核心用了 **WASM**」
- 「我們把影像處理的部分編譯成 **WebAssembly**，速度快了 10 倍」
- 「**WASM** 不是要取代 JavaScript，而是補足它效能不夠的地方」

## 為什麼要知道這個詞？

- 越來越多「以前只能裝軟體」的工具搬到瀏覽器上，背後都是 WASM
- 理解為什麼某些網頁應用能跑得跟桌面程式一樣快
- [Rust](rust.md) 語言的熱門應用場景之一
