# AI Agent — 自主做事的 AI 員工

> **白話說：** 一般的 AI 像客服——你問一句它答一句。AI Agent 像正職員工——你交代一個任務，它會自己規劃步驟、自己執行、遇到問題自己想辦法解決。

---

## 它到底是什麼？

**Agent**（代理人）指的是一個能**自主行動**的 AI。

差別在哪裡？

| | 一般 AI（聊天機器人） | AI Agent（代理人） |
|---|---|---|
| 你說 | 「怎麼做報告？」 | 「幫我做好這份報告」 |
| AI 做 | 告訴你步驟 | 自己去讀資料、整理、產出報告 |
| 互動模式 | 你問一句、它答一句 | 你交代任務、它整個完成 |
| 像什麼 | 問路的路人 | 你僱的計程車司機 |

## Agent 為什麼厲害？

因為 Agent 能做到三件一般 AI 做不到的事：

1. **規劃**：把大任務自動拆成小步驟
2. **執行**：直接動手做（讀檔案、改文件、跑程式）
3. **反思**：做完檢查結果，不對就自己修正

這就是 Claude Code 的運作方式——它不只是聊天，它是一個 Agent。

## Agent 團隊（特遣隊）是什麼？

一個 Agent 已經很強了，但如果**多個 Agent 一起合作**，就更厲害了——這就是「特遣隊」概念：

```
🎖️ 指揮官（你）
├── 🔍 偵察兵 Agent → 負責搜集資料
├── 📊 分析師 Agent → 負責整理分析
├── 📝 撰稿 Agent   → 負責寫報告
└── ✅ 品管 Agent   → 負責最終審查
```

每個 Agent 各司其職，就像一個小型的專案團隊。

> 💡 這是進階用法，初學者不需要一開始就學。先熟悉單一 Agent（Claude Code 本身）就很夠用了。

## 生活比喻 / 實際例子

想像你請了一個新來的助理：

- 你說「幫我訂晚餐」——一般 AI 只會告訴你附近有哪些餐廳；Agent 會直接幫你打開 App、選好餐、下單、付款，全部搞定才跟你回報「訂好了，8 點送到」
- 工程師常說：「我讓 Claude Code 這個 Agent 自己去改 Bug，它會自己找到問題、改程式碼、再跑測試確認有沒有修好」
- 客服如果換成 Agent，你不用一步一步教它「先查訂單、再查物流、再回覆客人」，你只要說「幫這個客人處理退貨」，它會自己判斷該做哪些事

## 為什麼要知道這個詞？

- 現在很多工具都打著「AI Agent」的名號在賣，知道差別才不會被行銷話術唬住——重點是看它「能不能自己動手做完，不只是給建議」
- 工程師之間討論「這個是不是 Agent」時，是在問「它會不會自己規劃步驟、自己執行」，不是單純的問答機器人
- Claude Code 本身就是一個 Agent，理解這個詞能幫你更清楚它能幫你做到什麼程度
