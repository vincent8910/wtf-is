# Codex（OpenAI） — OpenAI 的 AI 編程 Agent

> **白話說：** 如果 [Claude Code](claude-code.md) 是 Anthropic 派出的 AI 工程師，Codex 就是 OpenAI 派出的——兩個都能幫你寫程式，只是背後老闆不同。

---

## 它到底是什麼？

**Codex** 是 OpenAI 推出的 AI coding agent，跟 [Claude Code](claude-code.md) 是直接競爭對手。

它能做的事：
- 在終端機或 IDE 裡直接操作你的程式碼
- 根據自然語言指令寫新功能、修 Bug
- 理解整個專案的結構和上下文
- 執行指令、跑測試、做部署

Codex 的特色是跟 OpenAI 生態系深度整合——如果你已經在用 ChatGPT、GPT API，Codex 會是很自然的選擇。

```
AI Coding Agent 的競爭格局（2026）：

┌─────────────────────────────────────┐
│  閉源付費                            │
│  ├─ Claude Code（Anthropic）         │
│  ├─ Codex（OpenAI）                  │
│  └─ Gemini CLI（Google）             │
│                                     │
│  開源                                │
│  └─ OpenClaw（社群）                  │
└─────────────────────────────────────┘
```

## 生活比喻 / 實際例子

想像你要請一個 AI 助手幫你寫程式：

- **Claude Code** = 請 Anthropic 公司的工程師來幫忙
- **Codex** = 請 OpenAI 公司的工程師來幫忙
- **OpenClaw** = 請開源社群的志工來幫忙

每個都能幫你做事，差別在於能力偏好、價格、和你已經在用的工具生態。

**造句**：
- 「我們團隊一半用 Claude Code、一半用 **Codex**，看哪個順手」
- 「**Codex** 跟 ChatGPT 的整合比較好，如果你本來就用 OpenAI 的話」
- 「OpenAI 剛更新了 **Codex**，現在支援多檔案編輯了」

## 為什麼要知道這個詞？

- AI coding agent 是 2025-2026 年軟體工程最大的變革之一
- Codex 是這個領域的主要玩家，跟 [Claude Code](claude-code.md) 並列兩大閉源選項
- 了解各家工具的差異，你才能選擇最適合自己團隊的方案
- 面試或工作中越來越常被問到「你用什麼 AI 工具寫程式？」
