# Edge Computing — 把運算搬到離你最近的地方

> **白話說：** 以前所有運算都在遠方的機房（雲端）。Edge Computing 是把運算搬到離使用者最近的地方——就像便利商店比大賣場近，雖然東西少但拿得快。

---

## 它到底是什麼？

**Edge Computing（邊緣運算）** 是把資料處理放在靠近使用者的「邊緣節點」上，而不是全部送回遠端的雲端機房。

```
傳統雲端：
  使用者（台北）→ 請求飛到美國機房 → 處理 → 結果飛回台北
  延遲：200ms+

Edge Computing：
  使用者（台北）→ 請求到台北的邊緣節點 → 處理 → 馬上回覆
  延遲：10-20ms
```

Edge 的應用場景：
- **[CDN](cdn.md)**：靜態檔案放在全球各地的節點
- **Edge Functions**：程式碼也跑在邊緣節點（Cloudflare Workers、Vercel Edge）
- **IoT**：工廠的感測器在本地處理資料，不用全部傳回雲端
- **AI 推論**：手機上直接跑 AI，不用連網

## 生活比喻 / 實際例子

- **純雲端** = 所有信都寄到總公司處理，再寄回來（慢）
- **Edge Computing** = 每個分店都能直接處理，不用事事請示總公司（快）

**造句**：
- 「我們把 API 部署到 **Edge**，全球使用者的延遲都降到 50ms 以下」
- 「**Edge Computing** 對即時遊戲很重要，延遲差 100ms 體驗差很多」
- 「用 Cloudflare Workers 做 **邊緣運算**，不用自己管伺服器」

## 為什麼要知道這個詞？

- 2025-2026 年 Web 開發的大趨勢——越來越多框架支援 Edge 部署
- 跟 [CDN](cdn.md)、[Serverless](serverless.md)、[Latency](latency.md) 直接相關
- 對全球化產品來說，Edge 是提升使用者體驗的關鍵
