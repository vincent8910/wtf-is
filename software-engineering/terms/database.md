# Database（資料庫）— 超級進化版的 Excel

> **白話說：** Database 就像一個超強的 Excel，可以同時讓 100 個人查詢而不會當掉。

---

## 它到底是什麼？

**Database（資料庫，工程師常簡稱 DB）** 做的事本質上跟 Excel 一樣——**儲存和管理資料**。但它是 Excel 吃了超級星星的進化版。

| | Excel | Database |
|---|---|---|
| **資料量** | 幾萬筆就開始卡 | 幾億筆都沒問題 |
| **同時使用** | 多人編輯容易衝突 | 幾百人同時查詢也不亂 |
| **速度** | 資料一多就轉圈圈 | 有索引機制，秒查 |
| **安全性** | 誰拿到檔案誰就能改 | 帳號密碼、權限控管 |
| **備份** | 你要自己記得存 | 自動備份，壞了也能救 |

## 它藏在哪裡？

你每天都在「用」Database，只是不知道：

| 你做的事 | 背後的 Database |
|---------|----------------|
| 登入公司系統 | 查你的帳密是否正確 |
| 購物網站下單 | 記錄訂單、扣庫存 |
| 滑 IG | 撈出追蹤的人最新發的文 |
| 查銀行餘額 | 算出帳戶裡的錢 |

## SQL 是什麼？

偶爾會聽到工程師說「寫個 SQL 查一下」。**SQL** 就是跟 Database 溝通的語言：

```
中文版：「幫我找出所有 VIP 客戶，按消費金額從高到低排」
SQL 版：SELECT * FROM 客戶 WHERE 等級 = 'VIP' ORDER BY 消費金額 DESC
```

你不用學 SQL，但知道它存在就好。

## 日常場景

- **「我去查一下 DB」**
  → 去資料庫看一下資料
- **「Database 連不上，所有功能都壞了」**
  → 圖書館關門了，沒人能借書——整個系統癱瘓
- **「我寫個 SQL 撈一下，五分鐘」**
  → 用查詢語言去資料庫裡找你要的資料

> 💡 Database 就是系統的記憶。它掛了，App 就像失憶的人——什麼都不記得。

## 為什麼要知道這個詞？

- 幾乎每個產品背後都有 Database，聽到「資料庫掛了」「資料庫連不上」就知道等於系統全面癱瘓，是最高等級的問題
- 討論新功能時，工程師常會問「這個資料要存在哪裡」，理解 Database 的概念才能一起討論資料該怎麼設計
- 「Database 備份」「資料庫遷移」這類詞常跟風險評估有關，聽得懂才知道什麼時候該謹慎，什麼時候是小事
