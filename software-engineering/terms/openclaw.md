# OpenClaw — 2026 年最紅的開源 AI 編程 Agent

> **白話說：** 就像一個免費的、開源的 AI 工程師助手——任何人都可以下載來用、也可以改造它。OpenClaw 是社群共同打造的 AI coding agent，對標 [Claude Code](claude-code.md) 和 [Codex](codex.md)。

---

## 它到底是什麼？

**OpenClaw** 是一個開源的 AI coding agent，能在[終端機](terminal-cli.md)裡幫你寫程式、修 Bug、做重構。

它跟 [Claude Code](claude-code.md) 做的事情類似，但最大的差別是：

| | OpenClaw | Claude Code | Codex |
|--|---|---|---|
| 開源 | ✅ 完全開源 | ❌ 閉源 | ❌ 閉源 |
| 費用 | 免費（自備 API Key） | 付費 | 付費 |
| 可自訂 | 高（可以改原始碼） | 低 | 低 |
| 模型選擇 | 任意模型 | 只能用 Claude | 只能用 OpenAI |
| 社群 | 活躍的開源社群 | 官方維護 | 官方維護 |

OpenClaw 能做的事：
- 讀取你的整個專案，理解程式碼結構
- 根據你的自然語言指令修改程式碼
- 執行終端指令、跑測試
- 自動規劃多步驟任務

因為是開源的，開發者可以：
- 加入自己的工具和外掛
- 接入任何 [LLM](../../ai-ml/terms/llm.md)（不被綁定在某家公司）
- 針對自己的工作流程客製化

## 生活比喻 / 實際例子

想像你要請一個助手幫你工作：

- **Claude Code / Codex** = 請正職員工，能力強但要付薪水，而且只能用公司指定的方式工作
- **OpenClaw** = 請一個自由接案的助手，免費但你要自己管理，好處是你可以完全按照自己的方式訓練他

**造句**：
- 「我改用 **OpenClaw** 了，接 DeepSeek 的 API 超便宜」
- 「**OpenClaw** 的社群剛出了一個新外掛，可以自動寫測試」
- 「公司不想被 Anthropic 綁死，所以我們選了 **OpenClaw**」

## 為什麼要知道這個詞？

- 2026 年開源 AI 工具圈最熱門的專案之一
- 代表了「AI 編程工具不一定要付費」的趨勢
- 如果你是工程師，這是 [Claude Code](claude-code.md) 和 [Codex](codex.md) 之外的重要選項
- 開源意味著透明——你可以確認它不會把你的程式碼傳到奇怪的地方
