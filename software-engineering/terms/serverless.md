# Serverless — 不用管伺服器，程式碼丟上去就能跑

> **白話說：** 以前要自己租伺服器、裝系統、顧機器。Serverless 是你只管寫程式碼，雲端幫你搞定其他所有事——有人用就自動開機，沒人用就自動關機，按用量收費。

---

## 它到底是什麼？

**Serverless（無伺服器）** 不是真的沒有伺服器，而是你**不需要管理伺服器**。雲端供應商幫你處理所有基礎設施。

```
傳統方式：
  租伺服器 → 裝系統 → 部署程式 → 監控 → 擴容 → 付月費（不管有沒有人用）

Serverless：
  上傳程式碼 → 完成！
  有人用 → 自動執行 → 按次計費
  沒人用 → 不花錢
```

| | 傳統伺服器 | Serverless |
|--|---|---|
| 管理 | 你要管 OS、更新、安全 | 雲端全包 |
| 擴容 | 手動加機器 | 自動擴展 |
| 費用 | 固定月費（閒置也付） | 按使用次數付費 |
| 適合 | 持續高流量 | 流量不穩定、偶爾觸發 |

代表服務：AWS Lambda、Google Cloud Functions、Cloudflare Workers

## 生活比喻 / 實際例子

- **傳統伺服器** = 自己買車。不管開不開都要付保險、停車費、保養費
- **Serverless** = 叫 Uber。要用才叫，按趟計費，不用管車子保養

**造句**：
- 「這個 API 流量很低，用 **Serverless** 比較省錢」
- 「我們的圖片壓縮功能用 AWS Lambda 做 **Serverless**，上傳一張才觸發一次」
- 「**Serverless** 的冷啟動問題要注意，第一次呼叫會比較慢」

## 為什麼要知道這個詞？

- 小型專案和 side project 的首選部署方式——便宜又省事
- 跟 [Cloud](cloud.md)、[AWS](aws.md)、[Edge Computing](edge-computing.md) 直接相關
- 不是所有場景都適合——持續高流量反而比傳統伺服器貴
