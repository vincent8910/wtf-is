# Terraform / IaC — 用程式碼管理伺服器，不用手動點按鈕

> **白話說：** 以前開伺服器要登入雲端後台一個一個點。IaC 是把「我要什麼伺服器」寫成程式碼——像寫食譜一樣，跑一次就自動幫你把整個環境建好。

---

## 它到底是什麼？

**IaC（Infrastructure as Code，基礎設施即程式碼）** 是用程式碼來定義和管理雲端基礎設施的做法。**Terraform** 是最流行的 IaC 工具。

```
手動方式（傳統）：
  1. 登入 AWS 後台
  2. 點「建立伺服器」
  3. 選規格、設定網路、開防火牆...
  4. 重複 20 次（因為要 20 台）

IaC 方式（Terraform）：
  寫一個檔案：「我要 20 台 t3.medium 的伺服器，開 port 443」
  執行：terraform apply
  → 自動幫你建好 20 台，設定完全一致
```

IaC 的好處：
- **可重複**：同樣的程式碼跑 100 次，結果都一樣
- **可追蹤**：基礎設施的變更都有 [Git](git.md) 紀錄
- **可審查**：改設定要發 [PR](pull-request.md)，有人 review
- **可複製**：要建一個一模一樣的測試環境？跑同一份程式碼就好

## 生活比喻 / 實際例子

- **手動管理** = 每次做菜都憑感覺，味道每次不一樣
- **IaC** = 寫好食譜，照著做每次都一樣的味道

**造句**：
- 「我們所有基礎設施都用 **Terraform** 管理，不允許手動改」
- 「**IaC** 的好處是新人來了，看程式碼就知道我們的架構長什麼樣」
- 「用 **Terraform** 建一個新環境只要 10 分鐘，以前手動要半天」

## 為什麼要知道這個詞？

- [DevOps](devops.md) 工程師的必備技能
- 現代雲端架構幾乎都用 IaC 管理
- 跟 [AWS](aws.md)、[GCP](gcp.md)、[CI/CD](ci-cd.md)、[K8s](k8s.md) 密切相關
